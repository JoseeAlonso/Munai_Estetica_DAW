# Reflexión Final

**Proyecto:** Munai Clínica Estética
**Módulo:** 1709 · Itinerario Personal para la Empleabilidad I
**Autor:** Jose Enrique Alonso Bachek

---

## ¿Qué he aprendido?

Este proyecto me ha enseñado que hay una diferencia grande entre aprender algo en clase de forma aislada y aplicarlo en un proyecto real. Cuando tienes que construir algo que funcione de verdad —con varias páginas, coherencia visual y un formulario que refleja una base de datos— empiezas a entender por qué cada cosa existe y para qué sirve.

He aprendido a estructurar una web con HTML semántico, a darle estilo con CSS sin depender de ningún framework, a organizar el código en archivos con una responsabilidad clara y a adaptar el diseño a distintos tamaños de pantalla.

También he aprendido algo que no esperaba: que la organización importa tanto como el código. Tener el CSS dividido, el repositorio ordenado y el README bien escrito hace que el proyecto sea más fácil de entender, de mantener y de presentar.

---

## ¿Qué se me ha dado mejor?

La parte de diseño y maquetación. Una vez que entendí cómo funciona Flexbox y cómo encadenar clases en CSS, el proceso de convertir una idea en algo visual empezó a fluir con bastante naturalidad.

---

## ¿Qué me ha costado más?

Mantener la coherencia entre páginas. Al principio era fácil hacer cambios en una página sin pensar en las demás, y luego tenía que revisar todo para asegurarme de que el estilo seguía siendo consistente. La solución fue dividir el CSS en archivos independientes, lo que hizo que el mantenimiento fuera mucho más llevadero.

---

## ¿Qué mejoraría?

Le añadiría imágenes reales. Ahora mismo la web usa placeholders de color e imagenes ficticias del centro y sus empleados. Con imágenes reales, la diferencia visual sería muy grande y el resultado quedaría mucho más profesional.

También me gustaría añadir una pequeña animación de confirmación en el formulario de citas para que el usuario sepa que su solicitud ha sido enviada correctamente.
