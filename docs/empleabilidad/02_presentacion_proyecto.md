# Presentación del Proyecto — Munai Clínica Estética

---

## ¿Qué es Munai?

**Munai** es el portal web corporativo de una clínica estética y de fisioterapia ficticia.
Es el proyecto principal del curso, desarrollado como eje central del Proyecto Intermodular de 1º de DAW.

La web presenta a la empresa, muestra sus tratamientos y permite a los usuarios solicitar una cita o ponerse en contacto con el equipo.

---

## ¿Qué problema resuelve?

Una clínica estética necesita una presencia digital clara y profesional para que sus clientes puedan informarse sobre los servicios, conocer al equipo y reservar una cita sin tener que llamar por teléfono.

Munai responde a esa necesidad: es una web corporativa limpia, navegable y coherente que representa a la empresa de forma creíble.

---

## ¿Para quién está pensado?

Para clientes potenciales de la clínica que quieran conocer los tratamientos disponibles, ver los precios y horarios, o solicitar una cita.

---

## Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| HTML5 | Estructura semántica de todas las páginas |
| CSS3 | Diseño visual, responsive y animaciones |
| Google Fonts | Tipografía (Playfair Display + Open Sans) |
| Git y GitHub | Control de versiones y entrega del proyecto |

---

## Páginas que incluye

| Página | Descripción |
|---|---|
| `index.html` | Inicio: presentación, servicios destacados, equipo y testimonios |
| `servicios.html` | Catálogo completo de tratamientos con precios y duración |
| `citas.html` | Formulario de reserva en 5 pasos |
| `contacto.html` | Datos del centro, formulario de contacto, horarios y FAQ |

---

## Relación con la base de datos

Aunque la web no tiene backend conectado, el formulario de citas refleja la estructura de la base de datos del proyecto:

- Datos personales del cliente → tabla `clientes`
- Selección de tratamiento → tabla `tratamientos`
- Elección de profesional → tabla `empleados`
- Fecha, hora y estado → tabla `citas`
