## Sobre mí

Soy estudiante de primer año de DAW, un ciclo que elegí porque me interesa el mundo del desarrollo de software y quiero dedicarme profesionalmente a crear aplicaciones y webs.

Durante este primer curso he aprendido a construir páginas web desde cero con HTML y CSS, a diseñar bases de datos en SQL, a programar en Java y a trabajar con Git y GitHub como herramientas del día a día de un desarrollador.

## Qué estoy aprendiendo

- **HTML5 y CSS3** — estructurar y maquetar páginas web con semántica correcta y diseño responsive
- **SQL** — diseñar bases de datos relacionales y lanzar consultas
- **Java** — programación orientada a objetos y conexión con bases de datos mediante JDBC
- **Git y GitHub** — control de versiones, organización de repositorios y buenas prácticas de commits
- **Entornos de desarrollo** — configuración de proyectos y documentación técnica

## Qué tipo de proyectos me gustan

Me atraen los proyectos que tienen una utilidad real y que resuelven un problema concreto.
En este primer año he desarrollado **Munai**, el portal web de una clínica estética ficticia, y ha sido una buena forma de ver cómo todo lo aprendido en clase encaja en algo funcional y presentable.

## En qué me gustaría especializarme

Todavía estoy en proceso de descubrirlo. Este primer año me ha permitido tocar varias áreas — frontend, backend, bases de datos — y quiero seguir explorando las opciones antes de decidir.
Lo que sí tengo claro es que quiero construir cosas que funcionen bien, que sean útiles y seguras.

## Qué me motiva

La posibilidad de crear algo desde cero y verlo funcionar. También el hecho de que el desarrollo web es un campo que evoluciona constantemente y que siempre hay algo nuevo que aprender.
