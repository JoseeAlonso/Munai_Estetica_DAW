# Munai

Este proyecto es una web de una clínica estética y de bienestar llamada Munai. Está hecha solo con HTML y CSS, sin usar JavaScript ni frameworks.

La clínica está pensada como un centro en Madrid donde ofrecen tratamientos faciales, corporales, fisioterapia, depilación, manicura y cosas de relax.

## Archivos

- index.html -> página principal
- servicios.html -> donde están los tratamientos
- citas.html -> formulario para pedir cita
- contacto.html -> información de contacto y formulario
- css/ -> estilos de toda la web
- assets/ -> carpeta de imágenes utilizadas

## Imágenes

Las imágenes están en la carpeta assets. Si no están, la web sigue funcionando pero sin fotos. Se pueden cambiar por otras o usar imágenes de internet.

## Cómo verlo

Solo hay que abrir el archivo index.html en el navegador. No hace falta instalar nada ni usar servidor.

## Características

- HTML5 básico con etiquetas semánticas
- CSS3 con flexbox y grid
- Diseño responsive
- Menú tipo hamburguesa hecho con CSS
- Formularios con validación HTML
